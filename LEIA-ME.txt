VERSÃO CORRIGIDA

Para visualizar no PC agora:
1. Extraia o ZIP.
2. Abra a pasta enem14_mobile_pwa_corrigido.
3. Dê dois cliques em index.html.

O modo de aplicativo instalável e offline é ativado quando o site é publicado em um endereço http/https.

ENEM 14 — PWA mobile-first

O aluno não deve baixar este ZIP. O ZIP é apenas para você publicar o site.

COMO PUBLICAR SEM PROGRAMAÇÃO
1. Crie uma conta gratuita no Netlify.
2. Extraia esta pasta no computador.
3. Arraste a pasta inteira para a área de publicação do Netlify.
4. O Netlify fornecerá um link público.
5. Envie somente esse link aos alunos.

NO CELULAR
- iPhone: abrir no Safari > Compartilhar > Adicionar à Tela de Início.
- Android: abrir no Chrome > menu > Instalar aplicativo.
